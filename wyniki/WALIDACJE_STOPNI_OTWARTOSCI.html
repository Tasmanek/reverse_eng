MCOD 2.62.3 · ZESTAWIENIE REGUŁ

Stopień otwartości: walidacje i ponowne przeliczenie

Ręczne dodawanie zasobów oraz import CKAN i XML. Reguły istniejącej implementacji: brak stopnia 1–5, przydzielenie 1. stopnia i wyzwalacze ponownej oceny.

Kiedy nie zostaje przydzielony stopień 1–5Kiedy przydzielany jest 1. stopieńJakie zmiany i działania wyzwalają przeliczenieCo samo nie wymusza ponownego obliczeniaBłędy walidacji, które nie oznaczają automatycznie braku stopnia ani stopnia 1
Jak czytać wynik: 0 oznacza obliczony brak stopnia 1–5. Brak nowego przeliczenia lub błąd obliczenia może pozostawić poprzednią ocenę. 1 jest dodatnim wynikiem określonych reguł. Dla plików ocena zasobu to maksimum ocen pliku głównego i wszystkich pochodnych; dla linku bez pliku głównego ocenia się link. Format całego zasobu równy None daje wcześniej 0.

4. Co samo nie wymusza ponownego obliczenia

Co samo nie wymusza ponownego obliczenia
Zmiana / sytuacjaEfektWarunek dodatkowy
Sam opis, tytuł lub deklarowany formatBrak wyzwalacza w opisanej ścieżce; ocena może pozostać nieaktualna.Przeliczenie wymaga osobnej rewalidacji lub innego wyzwalacza.
Zmiana treści pod tym samym URLSam kalkulator nie monitoruje zmian na zewnętrznym serwerze.Potrzebne kolejne przygotowanie, ręczna rewalidacja lub kwalifikujący harmonogram.
Przeniesienie do innego zbioruW pokazanej gałęzi sygnału aktualizuje archiwa zbiorów.Samo przeniesienie nie wywołuje kalkulatora oceny.
Zmiana ustawień harmonogramuMoże utworzyć, zmienić lub anulować harmonogram.Przeliczenie następuje dopiero przy wykonaniu zadania spełniającego warunki z tabeli 3.
Nadpisanie istniejącego pliku głównegoSygnał process_created_file wymaga nowego rekordu.Dla istniejącego rekordu potrzebny inny wyzwalacz; nie zakładaj automatycznej oceny po każdym uploadzie.
Nowy szkic / sama zmiana statusu na publikacjęNowy szkic nie uruchamia standardowego przebiegu; sama zmiana statusu nie jest warunkiem is_link_updated.Pierwsza publikacja może uruchomić ocenę, jeśli spełniono warunek linku/dostępności lub inny warunek przygotowania.

5. Błędy walidacji, które nie oznaczają automatycznie braku stopnia ani stopnia 1

Błędy walidacji, które nie oznaczają automatycznie braku stopnia ani stopnia 1
Kontrola / błądRzeczywisty wpływ na ocenę
Nieudana kontrola URL, pliku lub danych tabelarycznych podczas przygotowaniaEntryPoint nadal próbuje obliczyć ocenę dostępnego stanu po przewidzianych etapach. Wynik zależy od formatu, źródeł i wyjątków samej oceny.
Timeout / błąd połączenia przy pobieraniu linku do kalkulatoraRequestException jest przechwycony. Przykładowo PDF → 1, XLSX → 2, CSV/JSON/XML → 3, RDF/JSON-LD → 4.
HTTP 404/500 przy pobraniu do samej ocenyTa funkcja nie sprawdza statusu HTTP; może ocenić treść odpowiedzi według zapisanego formatu. Wcześniejsza kontrola pobierania wymaga HTTP 200.
Niepoprawny JSON lub pusty grafZwykle 3, a nie 0 lub 1.
XML bez treści, błędny XML lub nieudany test przestrzeni nazw3. Po przejściu testu na 4 nieudany test RDF/powiązań pozostawia 4.
Niepoprawny RDF, pusty graf lub brak wymaganych powiązań4, a nie 0 lub 1.
Skutek ponownego przeliczenia: ocena może wzrosnąć, spaść albo pozostać taka sama. Pozostawione stare pliki pochodne nadal mogą podtrzymywać wyższe maksimum. Zapis oceny w bazie i odświeżenie jej widoku na portalu są osobnymi krokami. Stopień nie potwierdza poprawności, aktualności ani prawdziwości danych.
